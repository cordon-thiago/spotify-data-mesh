# data

Put the real Spotify extended streaming history export here (Phase 1 reads it from this folder).

**Everything in this folder except this README is ignored by git.** The export contains your IP address and a detailed record of what you listened to and when. This repository is public, so those files must never be committed. Synthetic data with the same schema lives in [../sample_data](../sample_data) instead.

Nothing in Phase 0 reads this folder, and the sample data generator refuses to write into it.
